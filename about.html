Tentang

Saya belajar dengan membangun

Bukan orang yang percaya pada coba-coba tanpa arah. Satu proyek, satu kesalahan, satu perbaikan, lalu lanjut.

Home / About

Nama saya Muhammad Afiq Yunanto. Saya mulai menulis kode saat belajar HTML di sekolah, langsung mencoba membuat satu halaman berisi nama dan foto. Tidak ada yang berjalan mulus — layout berantakan, gambar tidak muncul, dan saya hampir menyerah.

Titik baliknya ketika saya sadar: kesalahan di browser adalah pelajaran terbaik yang pernah saya dapat. Dari situ saya belajar JavaScript secara bertahap, lalu beralih ke framework frontend, backend, dan basis data.

Karena itu, cara saya belajar terasa melompat-lompat. Saya sering mengerjakan proyek kecil hanya untuk memahami satu konsep — membuat API CRUD, menghitung zakat dengan JavaScript murni, membangun generator QR. Semua repository itu publik dan masih bisa dibuka.

Yang membuat saya bertahan adalah kesukaan pada prosesnya. Mengubah kebutuhan, menemukan bug yang elusive, lalu menyelesaikannya dengan cara yang elegan — itu bagian yang paling saya nikmati.
