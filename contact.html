Apakah saya bisa magang atau bekerja sama secara freelance?
Bisa. Saya terbuka untuk magang sebagai web developer fullstack maupun proyek freelance. Yang paling membantu: deskripsi singkat tentang lingkup pekerjaan, durasi, dan teknologi yang akan dipakai.
Teknologi apa yang paling saya kuasai?
Untuk frontend: JavaScript, TypeScript, React, Next.js, dan Tailwind CSS. Untuk backend: Node.js dengan Express, serta PHP dengan Laravel. Untuk database: PostgreSQL, MySQL, dan Prisma ORM.
Saya kuliah di bidang Analisis Keuangan, apakah tetap bisa bekerja di web development?
Bisa. Latar belakang saya berawal dari pendidikan Rekayasa Perangkat Lunak, jadi saya sudah terbiasa membangun sistem dari nol. Studinya sekarang justru menambah sisi bisnis, sehingga saya bisa membaca kebutuhan dari dua perspektif sekaligus.
Berapa lama waktu pengerjaan sebuah proyek?
Tergantung kompleksitasnya. CRUD sederhana biasanya selesai 1–2 minggu; aplikasi fullstack dengan autentikasi dan laporan lebih lama. Estimasi selalu saya berikan setelah requirement dibahas.
Boleh pakai portofolio ini sebagai referensi belajar?
Silakan. Kalau Anda ingin membuat versi sendiri, saya senang membantu.
